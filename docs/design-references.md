# 홈·소개 랜딩 디자인 기준

확인 기준일: **2026-09-06**. 레퍼런스의 출시 연도가 모두 2026년이라는 뜻은 아니다. 아래 실제 사이트를 브라우저에서 열고 로딩 완료 후 화면을 확인했다. Spotify와 Apple Music은 이번 홈·랜딩의 시각 레퍼런스에서 제외했다.

## 공간과 인터랙션

| 실제 레퍼런스 | 확인한 화면 | 가져온 원리 | 가져오지 않은 것 |
|---|---|---|---|
| [Lusion](https://lusion.co/) | 밝은 회백색 바탕, 큰 검정·흰색·파란색 물체를 담은 WebGL 화면, 작은 내비게이션과 넓은 여백 | 화면 크기에 맞춘 물체의 스케일, 적은 요소, 실제 재질과 깊이 | 원본 3D 모델·코드·카피, 긴 로딩 진입 화면 |
| [Unseen Studio](https://unseen.co/) | 무음 진입 후 전체 화면을 쓰는 3D 건축 공간, 가운데 큰 타이포와 하나의 주 행동, 모서리 내비게이션 | 공간 위의 타이포 레이어, 억제된 조작부, 부드러운 깊이 변화 | 원본 장면·모델, 강제 진입 게이트, 자동 오디오 |

시점 보조 자료: [Codrops, The Craft Behind Memorable Digital Experiences: Inside Unseen Studio](https://tympanus.net/codrops/2026/07/20/the-craft-behind-memorable-digital-experiences-inside-unseen-studio), 2026-07-20. 개별 사이트의 확인 결과와 기사 소개를 혼동하지 않는다.

Lilac에서는 원본 장면을 복제하는 대신 실제 음악 카탈로그 아트워크를 사용한 **세 개의 레코드·재킷 조형**을 만든다. 배경은 따뜻한 회백색, 타이포는 검정, 전체 화면 크기의 히어로 안에 여백을 둔다. 기존 30장 앨범 벽과 작은 둥근 히어로 패널은 사용하지 않는다. 스크롤은 브라우저 기본 동작이며 음악 버튼은 캔버스와 독립적이다.

독립 `#/specials` 허브·상세 경로와 같은 모양의 행사 카드들은 롤백 대상이다. 검증한 회차·수상 기록·출처는 보존하고, 홈의 한 영역에서 행사를 바꾸고 결과를 펼친다. 별도 경로를 새 이름으로 다시 만드는 우회 구현은 하지 않는다.

## 이미지 출처와 사용 범위

공식 서버에서 내려받았다는 사실은 사용 허가를 뜻하지 않는다. 복제한 자료는 **로컬 디자인 시안·검토용**이며 공개 배포·상업 사용 전 각 권리자의 허가 또는 적용 가능한 사용 근거 확인이 필요하다. 원본 워터마크를 제거하지 않는다. NHK는 무단 전재 금지를 명시하므로 그 이미지·로고를 앱의 공개 에셋에 넣지 않는다.

각 사용 이미지의 실제 URL, 원본 비율, 최적화 파일, 권리 주의사항은 `frontend/src/awards/`의 출처 기록을 따른다. 키 비주얼은 편집 참고 자료이며 Lilac과 행사 주최자의 제휴나 공식 서비스를 의미하지 않는다.

## 유지할 동작

- 3D는 지연 로드하고 화면 밖·숨김 탭에서 멈춘다. OS 모션 줄이기와 명시적 정지 설정을 우선한다.
- 캔버스가 실패해도 정적 아트워크, 미리듣기, 링크가 남는다.
- 홈 국가·음악 분류와 원곡 확인 후 30초 미리듣기를 유지한다.
- 행사 선택은 키보드·터치로 접근 가능하며 결과와 출처는 홈에서 펼친다.
- 차트·스토어·개인 데이터·법무 원문은 이 시각 재구성으로 덮어쓰지 않는다.
