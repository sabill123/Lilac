# 어워즈 최신 발표와 수상 기록

2026-10-14 변경. 기존 홈 어워즈는 `data.ts`의 편집 수상 기록뿐이었고 `mama-2025`가 고정 첫 탭이었다. 자동 발표 수집 기능은 없었다.

## 변경

- 수상·출연 기록 탭은 확인된 개최 종료일(없으면 시작일) 내림차순. 기본 탭은 정렬의 첫 항목이며 임의 우선순위가 아니다. 기존 수상자·출처·연도는 변경하지 않는다.
- 위에 별도 `어워즈 최신 발표` 영역을 배치. 발표 날짜 내림차순, 시상식/발표 종류 필터, 공식 원문 링크, 최근 조회·수집 실패 표시.
- API `/api/live/awards`: MAMA, MTV VMAJ, MMA, MUSIC AWARDS JAPAN, 한국대중음악상, 골든디스크, 일본 레코드대상, NHK 홍백가합전.
- 백엔드 재수집10분, 캐시TTL10분. 최초 요청은1.5초 대기 후 pending이면 수집을 계속하며 화면은5초 간격 재확인. 일반 표시 중60초 간격으로 API 확인. 페이지 이탈 시 요청·타이머 해제.
- Render free의 휴면, RSS 색인, 원천 지연 때문에 실시간 즉시 반영을 보장하지 않는다.

## 출처와 범위

- 8개 시리즈의 Google News RSS를 제목·문맥으로 필터. MAMA/MMA의 연도 인접 약칭은 시상식 문맥에서만 허용. US VMAs, MMA 격투기, MAMA 밴드 등 제외. 과거 수상 경력으로 소개한 가수의 국가 독창 기사는 새 시상식 발표가 아니므로 제외.
- VMAJ는 공식 루트의 연도 링크를 발견해 공지 목록을 수집. 현재 확인된2026 landing은 discovery 실패 시 부트스트랩이며 다음 연도를 임의 생성하지 않는다. MTV CDN은 일반 요청에 무관한 React shell을 HTTP200으로 돌려줄 수 있어 브라우저 HTML Accept/UA로 요청하고 실제 뉴스 링크 존재를 검사한다. 실제 수집에서10월14일 VTR 출연 발표 포함6개 공식 공지 확인.
- MMA는 Kakao Entertainment 공식 newsroom 목록을 파싱. 날짜 없는 기사만 최대4개 본문 추가 조회. 실제10월14일 최종 라인업 공지 확인.
- MAMA는 CJ 공식 RSS와 보도 RSS를 병행. 공식 RSS의 가장 최근 확인 항목은8월28일 Fan Festa이고10월13일1차 라인업은 보도로 수집된다. Mnet 공식2026 awards 페이지는 이미지 중심·빈 alt라 명단 자동 추출을 주장하지 않는다. 공식 사이트 링크에서 확인할 수 있다.
- VTR/게스트/MC를 LIVE ACT 명단으로 바꾸지 않는다. 공지 원문 제목을 보존하며 출연진 배열을 생성하지 않는다. 라인업 완전성이나 공식 명단 전체를 확보했다는 뜻이 아니다.
- 공식 게시일·RSS 발행일과 수집 시각을 구분. 일자만 알려진 공지는 임의의 시각을 표시하지 않는다. 행사 연도는 제목에 명시된 연결 근거만 사용한다.
- 실패한 제공자의 이전 항목만 유지하고 이전 정보로 표시. 성공한 빈 결과는 이전 항목을 계속 살려 두지 않는다. 모든 소스 실패가 정상 갱신으로 오인되지 않도록 출처별 실패를 응답한다.

## 검증

`npm run test:home-awards`가 기존 편집기록/정렬/탭7개, 자동수집59개, 공식수집22개, UI/정렬/실패/취소24개 검사를 실행한다. 프론트 TypeScript·Vite 빌드도 별도 수행한다. 합성 테스트와 실제 네트워크 확인은 구분한다.

운영 반영 시 이전 계정·저장소 대규모 보강 커밋(`983d440`)과 분리해야 한다. 해당 보강에는 별도 점검·DB 마이그레이션이 필요하므로, 어워즈 변경만 기존 운영 커밋을 기반으로 적용한다. 기존 수상 이미지 파일은 추가하거나 교체하지 않는다.

## 후속 개선

- 시상식·발표 종류·공식/보도 출처 필터를 URL에 저장해 새로고침 후 복원한다. 결과·표시 건수와 재시도 버튼을 제공한다.
- 갱신 때 필터와 펼침 상태를 보존하고, 키보드 초점을 가진 공지가 8개 표시 범위 밖으로 밀려도 그 링크를 유지한다. 공지가 실제 사라지면 결과 안내로 초점을 옮기며 변경을 알린다.
- 공지에 수상·LIVE ACT·VTR/게스트/진행·예매가 함께 있으면 복수 분류한다. 팬 페스타와 VTR 라인업을 본행사 라이브 명단으로 추정하지 않는다.
- RSS 잘림·잘못된 링크·공식 URL의 잘못된 달력 날짜를 정상 0건으로 처리하지 않는다. 관련성 판정은 100개 이상의 무관한 결과 뒤에도 제한보다 먼저 수행한다.
- 실패한 출처의 기록은 120일 범위에서만 보존한다. 일반 캐시가 이전 값을 복구하더라도 응답 직전에 만료를 다시 검사한다. 새 정정 기사는 날짜가 과거로 바뀌어도 옛 캐시보다 우선한다.
- 전체 출처 실패를 캐시 쓰기 성공 때문에 최신 정보로 표시하지 않는다. 공식 게시 시각에 타임존이 없으면 확인된 날짜만 보존한다.
- 390px 실제 브라우저 iframe 뷰포트에서 한국어·일본어 가로 넘침 없음, 공식 VTR 필터3건, URL 재진입·새로고침 복원을 확인했다. 실물 휴대폰 성능 인증은 아니다.
