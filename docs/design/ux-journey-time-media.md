# 실제 팬 활동·서버 시간·이미지 개선 검증

검증일: 2026-11-02 KST. 대상은 Lilac-redesign-v2 작업 폴더와 5196/5197 격리 로컬 실행이다. 기존 미커밋 변경을 보존했다. 커밋·배포·실제 가입·결제·주문은 하지 않았다.

## 1. 홈 정보 우선순위
사진 배너 뒤에 티켓 오픈/팬클럽 선행 → 다가오는 내한/방일 공연 → 한일 페스티벌 → 현지 공연 → 전체/선호 소식과 보조 TOP 10 → 팬클럽 → 신보 → 커뮤니티 순으로 배치했다. 일본 에디션의 보조 차트는 기존 데이터 방향에 맞춰 한국 차트로 명시한다. 서버 KST 날짜로 종료된 행사를 제외하되, 진행 중인 공연과 날짜 미확인은 보존한다. 판매처 소재지를 공연 개최 국가로 간주하지 않는다.

## 2. 티켓 시각과 상태
서버의 /api/time(no-store), 왕복 시간 중간점, performance.now 경과를 공유 시계로 사용한다. 기기 시각을 서버 시각으로 대체하지 않는다. 헤더와 티켓 시계·초 경계 카운트다운을 함께 갱신한다. 오픈/마감마다 해당 영역을 즉시 바꾸고 공개 티켓 API를 배치당 한 번 재조회한다. 실제 티켓 목록의 tlCard와 공연 상세까지 같은 기준을 사용한다. 시간대 미명시·미동기·알 수 없는 판매 구간은 추측하지 않는다. 일정 통과는 잔여석/실제 접수 가능의 증명이 아니다.

실제 브라우저의 Date.now를 7시간 옮겨 서버 시계와 남은 시간이 정상적으로 2초 진행한 것을 확인하고 복원했다. 실제 18:00 마감에서는 마감 항목이 빠졌으며 18:00:00.004 KST에 로컬 티켓 API 재조회 한 번이 기록됐다. 예매처 원천 재수집이나 매진 상태 검증으로 확대 해석하지 않는다.

## 3. 팬클럽·구매 정보
공식 원문을 다시 수집해 Ringo Jam 해외 월회비 550엔·세금 포함을 표시했다. TWS의 검증된 Weverse 상품 원문을 사용해 단축 링크의 접근 가드를 유지하면서 판매 대상 문구·동일 화면 판매자를 보여 준다. 그 문구만으로 가입 자격을 보장하지 않는다. 오래된 파서 캐시는 규칙 버전으로 다시 확인한다. 실제 재수집 데이터와 화면을 함께 확인했다.

MGA 공식 스토어는 5개 판형의 각각 확인된 품번 상품 링크를 사용한다. 한국 배송 기록은 공식 Help의 해외 배송 안내와 별도 배송비·관세 안내를 근거로 고쳤다. 구매자 국가를 조회에 명시하며, 미수집 배송 여부는 불가가 아니라 null/미확인으로 남긴다. 다른 판매처의 첫 화면/목록 링크도 상품 상세인 것처럼 표시하지 않는다. 상품 사진과 앨범 커버는 구분한다.

## 4. 이미지 수집·표시
현재 공식 사진의 신선도 조건은 유지한다. 홈/아티스트 조회가 제한된 재확인 큐를 작동시키며, 기존 없음 판정은 규칙 버전·유효 기간에 따라 재확인한다. 대기/실행 합계 12개, 공식 사진 동시 3개, 동일 키 합치기와 실패 후 대기 시간을 둔다. 성공은 화면 갱신 주제로 전달한다. 이미지 주소 없음/불러오는 중/성공/실패를 구분하고 이미 확인한 대체 주소만 사용한다. 실제 아티스트 사진·앨범 커버가 공연 포스터의 대체인 경우 그 종류를 표시한다. 원문을 읽지 못했거나 신원을 확인할 수 없는 사진은 미확인으로 유지한다. 뉴스는 현재 원문 이미지 수집 필드가 없는 텍스트형 목록을 유지하며 가짜 썸네일을 추가하지 않았다.

## 5. 검증
회귀검사 결과는 임시 폴더 ux-final-tests.json에 보관한다. 실제 시간·티켓 소비 경로·중복 재조회 방지·화면 이탈 정리·사진 재수집·실패 대조군·원문 접근 가드·공개 API 경계 등을 포함한다. 빌드와 타입 검사를 통과했다. 500kB 이상 묶음 크기 경고는 남아 있다.

한국어/한국 에디션 및 일본어/일본 에디션에서 홈·티켓·MGA 팬클럽·TWS 팬클럽·음반 상세 5개 경로를 320/390/640/768/1024/1440px로 검사했다. 기본 60개 조합에서 가로 넘침 0건이었다. 배송 조회 국가 변경 뒤 음반 화면 12개 조건을 재검사해 넘침 0건, 5개 판형 링크와 미확인 배송 표시를 확인했다. 로딩 완료 이미지의 실패 0건이며, 화면 밖 지연 로딩 전체를 완료했다고 주장하지 않는다. 언어/에디션은 한국어/한국으로 복원했다.

## 6. 운영 경계
운영에는 쓰기·배포하지 않았다. 공개 운영 상태만 읽었으며 새 /api/time은 HTTP 404였다. 따라서 이 기록은 로컬 구현/실행/출력 검증이지 운영 반영 증거가 아니다. 운영 자동 수집 전체의 원천별 정상 완료도 이 로컬 검증으로 보장하지 않는다. 운영 반영에는 별도 승인과 백엔드·프런트 동시 반영 및 운영 재검증이 필요하다.
