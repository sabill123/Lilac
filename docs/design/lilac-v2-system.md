# Lilac 홈 디자인 · 현재 로컬 기준 (2026-10-25)

최신 지시는 배너의 시간 안내 문구 삭제, 국가별 배너 확대, 공연·신보·페스티벌 우선 배치, 티켓/선행 왼쪽과 인기 차트 오른쪽이다. 과거 3D 포스터 팬, 작은 고정 2열 정보판과 배너 앞 지원/아티스트 목록은 현재 방향이 아니다. 커밋·운영 배포하지 않았다.

## 홈의 읽는 순서

1. 아티스트 배너: 현재 공식 프로필 2초 → 같은 아티스트의 앨범 커버 또는 공연 이미지 2초. 2초/프로필 같은 구현 안내 문구는 화면에 쓰지 않는다.
2. 다가오는 내한 공연. 일본 화면에서는 방일 공연.
3. 새 앨범·싱글. 홈에는 실제 여섯 건을 보여주고 전체 목록으로 연결.
4. 한국·일본 음악 페스티벌.
5. 한 줄의 티켓/팬클럽 선행(왼쪽)과 인기 차트 TOP10(오른쪽). 960px 이하는 세로로 쌓는다. 티켓 표는 브라우저가 아니라 자신이 놓인 열 폭에 반응해 공연명이 지나치게 잘리지 않게 한다.
6. 현지 공연/원정 → 팬클럽 가입 → 커뮤니티/아티스트 커뮤니티 → 최신 소식.
7. 가입·구매·번역 도움과 판매처 검색 → 아티스트 이름 탐색 → 음악상.

배너와 첫 공연 섹션 사이에 설명·가입·아티스트 목록을 끼워 넣지 않는다. 상단 발견 콘텐츠를 우선하고, 참여/입력 도구는 그 뒤에 둔다. 흰 바탕·라일락 포인트, 사진과 큰 이름, 얇은 구분선을 유지한다. 장식 이모지·그라데이션 텍스트·발광·가짜 수치·반복 둥근 패널을 쓰지 않는다.

## 배너 데이터와 국가 구분

- 한국 화면은 일본 출신 아티스트, 일본 화면은 한국 출신 아티스트만 사용한다. 판매 국가나 예매처 분류가 아닌 정규 로스터의 origin으로 서버와 프런트에서 각각 검사한다. 앨범의 실제 판매 국가 필드는 덮어쓰지 않는다.
- 홈에 보이는 최근 발매12/공연8건과 배너 후보는 별개다. 전체 확정 공연, 기존 발매 기록과 정확한 아티스트의 카탈로그 앨범 이미지를 배너용으로 결합한다. 카탈로그 커버를 새로운 발매나 실물 상품 사진으로 꾸미지 않는다.
- mergedIds로 확인된 옛 아티스트 ID는 정규 ID로 연결한다. 이름이 같다는 이유로 이미지를 빌리지 않는다. 카탈로그 Apple 아티스트 ID가 충돌하거나 한 앨범 ID의 제목이 상충하면 제외한다.
- 후보 최대60명, 한 번에 표시 최대12명. 12명 이하 요청을 최대3개씩 처리한다. 서버의 실제 원문 수집 동시 실행은 별도로3건이다. 검증된 프로필을 중복 행의 null 값으로 덮지 않는다.
- 실제 로컬 확인: 한국 화면 J-POP12팀, 일본 화면 K-POP6팀(ILLIT, LE SSERAFIM, FTISLAND, TWS, CORTIS, Fromis 9). 수집 확인은 일본 아티스트20명/한국6명이며 모든 로스터의 사진을 찾았다는 뜻은 아니다. 배너는 검증·이미지 중복 조건을 거쳐 노출한다.

## 현재 공식 프로필의 근거

- 공식 사이트의 실제 프로필·약력 링크와 아티스트명/사진 문맥을 확인한다. 일반 OG, 홈페이지 티저, 멤버 개인 사진, 로고, 불명확한 복수 사진을 현재 그룹 프로필로 인정하지 않는다.
- 다국어 이름은 원래 로스터와 정확한 Apple 아티스트 ID 조회에서 확인한 표기만 사용한다. 임의 음역·아티스트별 주소 하드코딩은 하지 않는다.
- www/apex 같은 동일 사이트 변형은 안전하게 검증된 리다이렉트 주소로 한 번 재시작한다. 다른 도메인 이동은 공식 원문에서 실제 관찰한 meta-refresh가 정확한 아티스트 프로필 경로를 가리킬 때만 별도 확인하고, 새 페이지도 같은 신원·사진 검사를 통과해야 한다. 일반 외부 홈/뉴스/로그인/자격증명 URL은 따라가지 않는다.
- 확인 시각은 촬영·발표일이 아니다. 원문에 발표일이 없으면 null. 24시간 안에 확인한 공식 프로필만 배너에 사용하고, 실패한 재확인으로 checkedAt를 갱신하지 않는다. 새 검증 규칙은 과거 규칙의 성공/실패를 그대로 재사용하지 않는다.
- 안전한 HTTPS/DNS 고정, 익명 GET, 페이지/용량/시간 상한을 유지한다. 촬영일·현재 사진의 이용 권리까지 검증한 것은 아니다. JS 전용·멤버별 사진만 있는 사이트, 잘못되거나 사라진 공식 주소는 미확인으로 남긴다.

## 모션과 접근성

사진이 실제 로딩된 뒤 각2초를 센다. 다음 이미지가 준비되지 않으면 이전 사진과 이름을 함께 유지한다. 정지는 자동 전환만 멈추며 수동 이동은 유지한다. 포커스·호버·화면 밖·문서 숨김·모션 줄이기와 종료 정리를 존중한다. 이미지 등장 효과는0.25초다. 키보드/터치/탭과 원문 링크를 유지하고, 자동 전환을 스크린리더에 매번 강제 낭독하지 않는다.

## 실제 레퍼런스

[Rewire](https://www.rewirefestival.nl/)의 전면 사진, [Nuits sonores](https://nuits-sonores.com/en/)의 큰 글자와 구분선, [We Love Green](https://www.welovegreen.fr/?lang=en)의 라인업 표현, [Lissen](https://www.lissen.com/)의 실제 기능/출처 연결을 실제 페이지에서 조사했다. 타사 사진·브랜드 자산·상업 서체·코드는 복사하지 않는다. 고정 2열 SaaS 메인은 채택하지 않는다. 디스플레이는 기존 Host Grotesk 계열 토큰을 사용한다.

## 가입·구매 지원 기능

- `#/assist` / `#/assist?kind=fanclub&artistId=…` / `#/assist?kind=purchase&url=…`: 공식 공개 안내, 실제 발견한 입력 항목, 원문·번역 병렬 확인, 국가번호/가나 형식 도구.
- 팬클럽 상세에도 같은 도구를 삽입. 기존 플랫폼별 일반 가이드와 해당 아티스트에서 새로 수집한 근거는 구분한다.
- `GET /api/live/assistance`: 서버에 존재하는 정확한 팬클럽·상품 URL만 허용. 제목·이미지 URL·공개 안내 문구·폼의 라벨/필수 표시/선택지·원문 URL·수집 시각 수집. 입력값·비밀번호·인증·결제는 수집하지 않는다.
- HTTPS·공개 DNS 검사·연결 주소 고정·동일 출처 리다이렉트 검사, 최대 3페이지·페이지당 1MiB·전체 12초. 이미지 전용 수집은 1페이지. 동시 3건·요청 합치기·15분 메모리 캐시, 실패 캐시는 10초. 새로운 백그라운드 루틴이나 알림 없음.
- 실제 상품 상세에서 발견한 같은 판매처의 링크와 정확한 카탈로그 번호가 일치할 때만 판형별 이미지 연결. 하드코딩한 아티스트 예외나 URL 추측 없음. 회원 한정 등 실제 구매 조건은 해당 상품 원문에서 재확인하도록 표시한다.
- 앨범 커버와 원문 상품 이미지는 구분. 찾지 못한 사진은 가짜 이미지로 채우지 않는다. 종료된 예약 캠페인을 현재 특전으로 표시하지 않는다.

### 기기 내 실시간 번역

Chrome 공식 `Translator` API 사용. 일본어↔한국어 방향 선택, 사용자가 시작 버튼을 눌러 모델 다운로드 승인, 진행/중지 안내, 입력 후 자동 번역, 수집한 공개 원문의 번역을 제공한다. 방향 변경 때 내용 삭제, 이전 요청 응답 차단, 화면 제거 때 번역기 해제. 원문은 Lilac 서버나 클라우드 번역 서비스에 보내지 않고 저장하지 않는다.

[공식 문서](https://developer.chrome.com/docs/ai/translator-api): 지원 브라우저와 언어 모델이 필요하며 모바일/비지원 브라우저에서는 동작을 보장하지 않는다. 비지원 상태는 명시하고 원문 정보·형식 도구는 유지한다. 외부 Google 번역은 보조 링크일 뿐 실시간 번역 성공으로 취급하지 않는다. MyMemory는 장기 저장 약관 때문에 채택하지 않았다.

로그인 뒤에만 나오는 폼, 자바스크립트 실행 뒤 생성되는 필드, 개인별 가입 자격은 정적 공개 원문 수집만으로 검증하지 못한다. 공개 상품 수량란을 회원가입 필수 항목으로 단정하지 않는다. 자동 가입·주문·결제·인증 우회·개인정보 자동 제출은 구현 범위가 아니다.



## 이전 로컬 검증 환경과 범위

별도 redesign-v2 작업 폴더와 임시 공개 데이터 DB, 운영 자격증명 없이 백그라운드 작업을 끈5196/5197 로컬 환경이다. 5198 프레임 검사는 세션 임시 설정만 SAMEORIGIN이며 실제 프런트 DENY 헤더는 유지한다. 원래 Lilac 폴더의 다른 작업을 덮어쓰지 않았다.

- 실제 한국/일본 두 화면을320/390/768/960/961/1024/1440/1920px, 총16개 조합에서 확인했다. 문서/본문 가로 넘침0. 960 이하 차트가 티켓 아래, 961 이상 같은 높이의 오른쪽. 첫 순서는 배너→공연→발매→페스티벌→티켓/차트다. 시간 안내 문구가 없고 배너가 각각12/6팀임을 확인했다.
- verify-home-cover38개와 변이26개, verify-home-hub11개와 변이11개로 실제 모듈의 시간/소유/국가/정리/배치/요청 분할을 확인한다. 모의 DOM·정적 CSS 검사는 실제 브라우저 위치 측정과 구분한다.
- verify-cover-media, verify-portraits-routing, verify-official-portraits23개, verify-public-html, verify-profile-handoff로 국가·정규 ID·출처·수집 경계·변조·재확인 실패를 검사한다. 원래 가입/구매/번역/경로 검사는 유지한다.
- 빌드·git diff --check 통과. 공유 Three 묶음552KB 경고는 남는다. 전체 npm test 또는 사용자 디자인 승인을 주장하지 않는다.
- 기기 내 번역의 의미 오역 가능성, 로그인 뒤 항목·회원 자격과 사진 권리는 별도 한계다. 신규 공식 프로필 첫 수집은 원문 응답을 기다릴 수 있으며 보이는 홈 목록과 배너 후보 수집은 구분한다.

## 2026-11-03 밝은 팬 허브 배포 대상

- 첫 화면의 3줄 소개는 제거했다. 공식 프로필 사진이 화면 높이에 맞춰 시작하며, 커뮤니티 진입과 아티스트 선택·정지 조작을 같은 화면에 둔다. 공연 상세·팬클럽 가입 도움·정보 출처는 사진 바로 아래에서 이어진다.
- 사진 자체에 Three.js 정점 변형·포인터 시차를 적용한다. 앨범·공연 이미지는 전체가 보이는 배치, 프로필은 화면 채움 배치다. 움직임 감소·화면 이탈·비활성 문서에서는 정지하며, 12초 로드 제한·최신 이미지 토큰·컨텍스트 복구·자원 해제를 갖춘다. GPU용 이미지 긴 변은 데스크톱2048/모바일1024로 제한하며 원본 DOM 사진은 바꾸지 않는다.
- 커뮤니티로 이어지는 사진·이름 흐름을 최대72명/3행으로 구성한다. 실제 인원은 해당 국가 로스터에 따른다. 키보드·모션 감소·호버·터치 누름·사용자 정지를 지원하고 장식 복제는 접근성 탐색에서 제외한다.
- 곡·앨범·수상작 제목은 원문을 유지한다. 공개 원문 번역은 자동 번역·읽기 보조이며 정확성을 보장하지 않는다. 원문 보기와 출처를 유지하고, 사용자 글·개인 입력은 번역 대상에서 제외한다.
- 현재 로컬 실제 브라우저에서320/360/390/768/1024/1440/1920px 가로 넘침0과 커뮤니티 진입을 확인했다. 모의 검증은 npm run test:fan-hub, 빌드는 npm run build --prefix frontend로 실행한다. 전체 npm test 또는 WCAG 전면 인증을 뜻하지 않는다.
