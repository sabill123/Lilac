# Lilac 제품 페이지 디자인·UIUX 개선

## 현재 상태

2026-10-29 로컬 redesign-v2 작업에 적용했다. 커밋·운영 배포·운영 데이터 쓰기는 하지 않았다. 이전 작업은 수정 전 패치와 소스 백업을 세션 임시 폴더에 보존했다.

요청된 ai-design-skills(elayadesign)와 그 원문이 연결한 redesign-existing-projects를 읽고 기존 프로젝트 진단→우선순위→구현 순서로 사용했다. 선택 스킬은 실행형 CLI가 아니라 지침 모음이다. 원문 참조: ai-design-skills ded7efc9d5c02761c41a03caf3b78f9259ab8828, redesign-skill 7df13f6a289f4a7f91c5fe3efd70f51fd584ec28.

## 개선 전 → 후

- 큰 사진만으로 시작해 제품의 목적이 흐림 → 국가별 대상·공연/팬클럽/음반 목적을 밝히는 소개, 명시적인 아티스트 찾기. 사진 배너·동일 아티스트2초+2초·공연→신보→페스티벌→티켓/차트 순서는 유지.
- 메인 사진 위 그라데이션 → 평평한 명찰형 제목과 실제 사진. 제목·부제·날짜·출처 위계를 분리하고 원문 링크는 펼쳐서 확인 가능.
- 여러 라틴 글꼴/임의 크기/혼합 아이콘 → 자체 호스팅 Manrope, 한일 문자 대체 글꼴, 수치용 Geist Mono. 타입 단계·간격 토큰, Phosphor42개 심볼. 라이선스와 원문 출처 보존.
- 모바일 가로 메뉴 레일 의존·공연 하단 진입 부재 → 플로팅 헤더와 검색/18목적지 전체 높이 메뉴, 하단 홈/공연/팬클럽/커뮤니티/MY.
- 네이티브 메뉴 끝에서 브라우저로 초점이 이동 → Tab/Shift+Tab 끝점 명시적 순환, Escape·경로 변경·재렌더 시 닫기/초점/스크롤 복구.
- 팬클럽 조건·검색 결과에서 복구가 모호 → 현재 조건/전체·결과 건수/단일 초기화, 빈 결과와 실패 구분.
- 뉴스 주제/아티스트 필터가 누적된 상태를 찾기 어려움 → 조건 요약·초기화,8개씩 더보기 유지.
- 상세의 도움 도구가 핵심 조건보다 앞섬 → 공연의 언제/어디서/방식/미확인 조건, 팬클럽 조건→요금→방법→입력 도움, 음반 판형→판매처 확인 순서.
- 출처 정보가 없는 배송을 불가로 단정/모바일 CTA 숨김 → 미확인 상태 그대로 표시하고 조건/도움 진입을 모바일에서도 제공.
- 일시 알림이 클릭 불가하고 닫을 수 없음 → 읽을 수 있는 상단 알림, 닫기 버튼·단일 타이머·한국어/일본어 이름.
- 경로 오류의 숫자/주소만 노출 → 브랜드와 실제 홈·검색·이전 페이지 복귀.

## 스킬을 제품에 맞게 적용한 경계

Lilac은 광고용 단일 전환 랜딩이 아니라 여러 팬 활동을 지원하는 홈/제품이다. 따라서 가짜 후기·고객 로고·절감 수치·판매 보증·무료 체험을 만들지 않았다. 사용자의 명시적 금지인 그라데이션 제목·무관한 이미지·장식 이모지를 적용하지 않았다. 강제 태그라인/마케팅 FAQ를 공연 앞에 끼워 넣지 않고 기존 섹션 순서와 실제 기능을 보존했다. 화면마다 내용을 숨긴 뒤 등장시키지 않는다. 기존 유동형 요구를 유지하는 배너에는 지정 타입 단계의 양끝을 사용한 clamp를 두고 나머지는 공통 단계로 정리했다. 한/일 글리프는 Manrope가 제공하지 않아 기존 문자별 대체 글꼴을 유지한다.

## 실제 검증

- 336개 조합: 한국·일본 각28개 상태 × 320×568/390×844/768×1024/1024×768/1440×900/1920×1080. 이번에는 실제 page.setViewportSize 사용. 문서·본문 넘침/헤더 화면 이탈 0건.
- 보조 품질 검사로 공식 Impeccable 브라우저/WASM 검사기를390/1440px 112개 상태에 실행. 마지막 반환 경고·안내 0건. 검사기 자체를 제품에 포함하지 않았다.
- 실제 모바일 메뉴24번 Tab으로18개 링크 순환, Shift+Tab 역순, 메뉴 검색→인코딩된 실제 검색 경로, 닫기·스크롤 복구 확인. 초기 네이티브 키보드 끝점 문제는 수정 후 재검증했다.
- 실제 팬클럽 검색0건→초기화→48개 복구와 검색 초점 복원 확인. 회비/조건은 데이터 스냅샷이며 가격의 현재 사실이나 가입 자격을 보증하지 않는다.
- 공연 내부 안내 탭/음반 판형 이동/팬클럽 조건·입력 도움 이동을 실제 브라우저에서 확인했다. 외부 예매/가입/결제는 실행하지 않았다.
- 배너에 표시된 MGA 공식 사진은 원문 URL과2000px 이미지 로딩을 확인했다. 이미지 이용 권리·발표일을 검증했다는 뜻은 아니다.

## 남은 한계

운영 배포·공식 프로필의 주기 수집 연결은 별도다. 백엔드 자동 수집은 이번 디자인 범위에서 수정하지 않았다. 기존552KB Three 공유 청크 경고는 남는다. 로그인·계정 쓰기·실제 가입/결제·물리 휴대전화 터치·모든 보조기술에 대한 인증은 수행하지 않았다. 번역 의미 정확성·로그인 뒤 조건·외부 사이트 현행성/권리는 별도 확인 대상이다.
