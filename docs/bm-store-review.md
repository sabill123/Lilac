# 스토어 BM 점검 — 왜 지금은 커머스가 아닌가

작성: 2026-09-01 · 대상: `db/products.json`, `#/store`, BM 사다리 1단(커머스)

---

## 1. 현재 상태 진단

### 1-1. 상품이 아니라 앨범 메타데이터다

`db/products.json` 450건은 전부 `it-` 접두사, 즉 **Apple 카탈로그에서 파생된 앨범 레코드**다.
실제 판매되는 물건(음반 사양, 굿즈)이 아니라 음원 메타데이터에 가격을 얹은 것이다.

### 1-2. 가격의 75%가 지어낸 값

| | 건수 |
| --- | --- |
| `editions[].real === true` | 240 |
| `editions[].real === false` | **716** |

`real: false`는 실제 판매가를 확인하지 못하고 규칙으로 만들어낸 값이라는 뜻이다.
화면은 이 둘을 구분해 보여주지 않는다. 즉 **사용자는 어느 가격이 진짜인지 알 수 없다.**

### 1-3. 링크가 상품 페이지가 아니라 검색 결과 페이지다

```
https://tower.jp/search/item/{앨범명}
https://www.aladin.co.kr/search/wsearchresult.aspx?SearchWord={앨범명}
```

전 450건이 이 두 패턴뿐이다. 실제로 눌러보면 200이 오고 결과도 24~25건 나오지만,
**사용자는 일본어 검색 결과 목록에서 자기가 원하는 사양을 직접 찾아내야 한다.**
그 지점에서 라일락의 역할은 끝난다.

### 1-4. 결론

지금 구조로 얻는 수익은 **0원**이다.

- 거래가 라일락 밖에서 일어나므로 중개 수수료가 발생하지 않는다
- 제휴 링크도 아니라 어필리에이트 수익도 없다
- 구매 데이터가 남지 않아 B2B 단계(팬 데이터)로 올라갈 자산도 쌓이지 않는다

BM 사다리의 1단(커머스, 마진 5~15%)이 **구현된 것이 아니라 그려져 있을 뿐**이다.

### 2-3. 그래서 "링크 이상"은 이것이다

**링크가 하는 일**: 판매처 검색 결과로 보낸다. 정보 비대칭은 그대로 남는다.

**라일락이 해야 하는 일** — 우선순위 순:

1. **판매처 × 사양 정규화** — 흩어진 조합을 하나의 표로 모은다.
   같은 앨범인데 어디가 얼마고 특전이 뭔지 한 화면에서 비교된다.
2. **한국 팬 기준 최종가 환산** — 정가가 아니라 환율·수수료·배송비를 합친 실제 지불액으로 비교한다.
   판매처마다 배송 조건이 달라서 정가 비교는 의미가 없다.
3. **특전 번역·정규화** — 「巾着袋」가 뭔지 모르는 사람이 대부분이다.
4. **예약 마감·재입고 감시** — 링크는 시점을 못 알려준다.
   GREEN CODE 예약 기간(2026-06-19 ~ 09-17)처럼 **놓치면 끝나는 창**이 실재한다.
5. **(다음 단계) 공동구매 + 대행 결제** — 여기서 처음으로 수수료가 발생한다.

1~4는 계약 없이 지금 할 수 있고, 5는 판매처 제휴가 필요하다.
**1~4를 해두는 것이 5의 협상 재료**가 된다 — 트래픽과 수요 데이터를 들고 가야
정식 벤더 지위를 요구할 수 있다.

## 3. 데이터 모델 변경

기존은 `Product`(앨범 = 가격) 평면 구조라 판매처 개념 자체가 없었다.

```
Release          하나의 발매        (MGA 6th album, TWS NO TRAGEDY)
  └ Edition      사양               (초회한정반 CD+BD, Compact HUSH)
      └ Offer    판매처별 판매 건    (타워레코드 · 특전 巾着袋 · ¥4,400 · 예약중)
```

- **가격은 Offer에 있다.** Edition은 사양일 뿐이고 같은 사양도 판매처마다 값이 다르다.
- **특전은 Offer의 속성이다.** 이것이 이 모델의 존재 이유다.
- Offer는 `verified` 플래그를 갖는다. 확인한 값과 추정치를 화면에서 구분한다 —
  지금처럼 `real: false`를 숨기지 않는다.

## 4. 하지 않기로 한 것

- **전매·양도 중개**: 일본은 2019년 부정전매금지법으로 티켓 전매를 형사처벌한다.
  사업 범위에서 명시적으로 제외한다.
- **스크래핑 상시 운영**: 판매처 이용약관과 충돌한다.
  수집은 공개된 특설 사이트·공식 발표 기준으로만 하고, 출처를 데이터에 남긴다.
- **가격 지어내기**: 확인 못 한 값은 `verified: false`로 두고 화면에서 그렇게 보여준다.
