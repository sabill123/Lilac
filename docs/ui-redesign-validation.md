# UI 리디자인 검증 기록

## 적용 범위

공통 토큰, 기본 타이포, 버튼·입력·카드·칩·빈 상태, 상단 메뉴, 모바일 검색과 5탭 메뉴, 플레이어, 온보딩·모달·푸터를 정비했다. 홈은 음악 발견 → 아티스트·차트·일정 → 앨범 탐색 흐름으로 다시 구성했다. 차트·검색·스토어·상품·릴리스·일정·아티스트·보관함·워크·인증·계정·주문 및 소개·요금·FAQ·문의·법무·404에 공통 스타일을 적용했다.

실결제·배송·풀트랙 스트리밍을 새로 구현한 작업은 아니다. 데모 한계를 숨기지 않도록 문구를 정비했고 법무 원문은 보존했다.

## 자동 검사

- 프로덕션 타입 검사·빌드: 성공
- 서비스·UI 소스 계약: 131 통과, 0 실패
- 플레이어 UX 회귀: 9개 그룹 통과
- git diff --check: 통과
- 독립 Chrome 자동 캡처: macOS SIGABRT로 차단, 캡처 0. 성공으로 집계하지 않았다.

## 실제 브라우저 대체 검수

최신 dist와 실제 로컬 API를 연결한 별도 iframe 검수 페이지에서 390×844와 1440×900을 검사했다. 사용자 계정 생성이나 구매는 실행하지 않았다.

### 390px: 29개 화면 상태

홈, 차트, 스토어, 릴리스 목록, 일정, 아티스트 목록, 게스트 보관함, 상품 상세, 아티스트 상세, 발견 릴리스 상세, 큐레이션 릴리스 상세, 주문·계정의 로그인 이동, 로그인, 가입, 이용 안내, 상태, 워크, 검색, 소개, 요금, FAQ, 문의, 이용약관, 개인정보, 처리위탁, 앱 404, 사이트 404를 순회했다. 중복 로그인 도착 상태와 홈·스토어 재검수를 포함하므로 고유 URL 29개를 의미하지 않는다.

### 1440px: 25개 화면 상태

홈, 차트, 스토어, 릴리스 목록, 일정, 아티스트 목록, 게스트 보관함, 상품 상세, 아티스트 상세, 큐레이션 릴리스 상세, 로그인, 가입, 이용 안내, 상태, 워크, 검색, 소개, 요금, FAQ, 문의, 이용약관, 개인정보, 처리위탁, 앱 404, 사이트 404.

### 확인 항목과 수정

- 각 렌더링 화면 h1 1개와 제목이 상단 메뉴 아래에 있는지 확인
- 검사 시 완료된 이미지 중 깨진 이미지 0개
- 앱 본문 가로 넘침 0px. 사이트 모바일 루트는 내부 2px 차이가 있으나 뷰포트 밖 넘침 없음
- 소개의 복제 캐러셀과 릴리스 버전 탭은 의도한 내부 가로 이동 영역으로 분리
- 스토어 첫 제목이 긴 안내 아래로 밀리던 문제 수정, 이용안내 접기·모바일 미리보기 가로 목록 적용
- 모바일 검색과 언어 버튼 표시 복구
- 온보딩·모달 화면 높이 제한과 내부 스크롤 적용
- 차트 상단 음수 여백으로 제목이 가려지던 문제 수정
- 마지막 모바일 캡처에서 발견한 플레이어·메뉴 겹침 수정 후 재검수: 플레이어 y=720–784, 메뉴 y=784–844, 겹침 0px

## 미검증 범위

로그인된 계정·주문 상세·개인 플레이리스트의 실데이터 상태, 가입·결제·공동구매의 쓰기 경로, 외부 Apple Music 계정 연동, 실제 iOS/Android 기기와 모든 중간 화면 폭은 검증하지 않았다. 이 화면들의 공통 스타일 적용과 실제 동작 검증은 구분한다.

## 재실행

`npm run build`, `npm run test:ui`. Chrome 실행이 허용되는 환경에서는 `OUT=/absolute/tmp/audit npm run test:visual`도 실행할 수 있다. 기존 smoke 검사는 계정·구매 관련 데이터를 변경하므로 이번 검증에서는 실행하지 않았다.


## 음악 중심 후속 개선

앞선 홈 구성을 `discovery/` 공통 렌더러로 대체했다. 홈은 미리듣기·인기 TOP10·상승·신규 진입·주목·검증된 신인·아티스트·최근 발매 순서다. 차트는 국가·출처·검색·분류 필터와 대기열을 제공한다. 스토어는 별도 커머스 화면으로 유지한다. Apple Music 실제 화면을 참고했고, 기존 3D 비활성 계약은 지연 로딩·정지·정적 대체 화면의 행동 계약으로 갱신했다.

### 검사 결과

- 프로덕션 타입 검사·빌드 성공. Three 지연 청크 약 513KB에 대한 Vite 크기 경고는 남아 있다.
- 서비스 계약 131, 플레이어 9개 그룹, 스토어 20개 그룹, 발견 모델 18개 그룹, 발견 UI 20개 그룹 통과. 3D 생명주기·취소·텍스처·접근성 검사 통과.
- `git diff --check` 통과. 계정·구매를 생성하는 smoke 검사는 실행하지 않았다.
- 실제 브라우저에서 홈과 차트 각각 320/390/768/1024/1440px, 총 10개 폭·경로 조합 재검수. h1 각 1개, 제목의 헤더 가림 없음, 본문 가로 넘침 0, 로드 완료된 가시 이미지 오류 0, 플레이어·하단 메뉴 겹침 0. 각 씬의 `ready` 상태 확인.
- 실제 홈 WebGL 프레임 변화 확인, 모션 정지 후 프레임 동일 확인. API/텍스처/WebGL 실패와 reduced-motion은 자동 검사에서 별도 확인한다.
- 일본 Billboard에서 상승 9곡·신규 진입 21곡 확인. 검색 `=LOVE`는 원래 1/85/100위 유지. 한국 전환 시 지원하지 않는 Billboard 경로가 통합 경로로 수정되는 것을 확인했다.
- 키보드 Enter와 히어로 버튼으로 `恋、はじめました。 · =LOVE`를 실제 미리듣고 재생 시간 진행 확인 후 정지했다. 관련 없는 첫 검색 결과를 재생하지 않는 ID/전체 제목·아티스트 일치 검사도 통과했다.
- 390px 차트 첫 행 상단을 약 827px에서 626px로 줄여 플레이어 상단 720px 전에 노출했다. 상단 2/3위의 중복 카드만 모바일에서 숨기고, 해당 곡은 목록에 보존했다.
- 모바일 곡 메뉴가 플레이어 아래로 열리는 오류를 실제로 재현하고 수정했다. 수정 후 메뉴 범위 y=383–637, 플레이어 상단 y=720. Escape로 닫기와 summary 포커스 복귀 확인. 공간에 따른 상·하 배치, 작은 높이에서 내부 스크롤, 스크롤·리사이즈 재배치를 구현했다.
- 아트워크 없는 출처는 같은 국가의 통합 자료와 전체 아티스트·제목이 일치할 때만 커버/Apple 링크를 보완한다. 원래 순위·변동·출처별 순위는 보존한다.

분류 근거와 데이터 한계는 `frontend/src/discovery/README.md`, 3D 계약은 `frontend/src/three/README.md`에 기록했다. 신인 근거 목록은 완전한 전체 아티스트 데이터베이스가 아니며, NEW를 신인으로 바꾸지 않는다. 실제 기기, 외부 Apple Music 계정 승인과 풀트랙 재생은 검증 범위 밖이다. 독립 Chrome 실행 차단은 앞선 기록과 동일하게 대체 브라우저 검수와 구분한다.


## 이전 이력: 특설 페이지 추가

아래는 제거한 이전 버전의 기록이다. 독립 허브·상세 경로는 2026-09-06 후속 재작업에서 롤백했으며 현재 유지 경로가 아니다.

`#/specials`와 7개 회차 상세, 홈 인기 TOP10 다음의 특설 섹션을 추가했다. KMA·MUSIC AWARDS JAPAN·골든디스크 2026, MAMA·MMA·일본 레코드대상·NHK 홍백가합전 2025의 주요 기록을 출처와 함께 수록한다. 전체 수상 명단이 아닌 범위는 각 페이지에 표시하며, 홍백은 팀 대결 결과·출연 곡목으로 구분한다.

- 실제 브라우저: 허브·7개 상세·없는 회차·홈 10개 경로를 320/390/768/1024/1440px에서 검사, 총 50개 경로·폭 조합. h1 1개, 제목의 헤더 가림 없음, 본문·문서 가로 넘침 0, 메뉴·검색 겹침 0, 플레이어·하단 내비게이션 겹침 0. 홈 특설 카드 7개를 모든 폭에서 확인했다.
- 국가·연도·유형 AND 필터 7→4→2→0과 초기화, 아티스트·작품 검색, MAMA 대상 필터 12→4, APT. 검색 4→1, 새로고침·목록 복귀 시 필터 유지 확인.
- 입력란 blur의 change 이벤트가 클릭 대상을 다시 만들어 첫 클릭을 막던 오류를 수정하고, 실제 첫 클릭 및 자동 회귀로 확인했다.
- 수상작 음악 검색으로 APT. 원곡이 상위 결과에 표시되는 것을 확인했다. 검색 연결이며 자동 재생·전체 카탈로그 가용성을 보장하지 않는다.
- 모바일 상세의 중복 워드마크를 숨기고 필터를 압축했다. 390px MAMA 첫 수상 기록 상단 y=824에서 약538로 개선, 플레이어 상단 y=720보다 먼저 노출된다.
- 특설 전용 실제 TS 모델·데이터·뷰·컨트롤러 24개 검사 그룹 통과. 기존 계약 131, 플레이어 9, 스토어 20, 발견 모델 18·UI 20, 3D 생명주기 검사도 통과했다. 빌드 성공, 기존 Three 지연 청크의 500KB 초과 경고는 남는다.

자료 검증은 주최·방송·아티스트 공식 자료와 명시된 일부 언론 보도를 확인한 편집 기록이다. 테스트의 인용 검사는 참조 무결성 검사이지 원격 사실 재검증이 아니다. 자동 수상 집계, 전년도 전체 이력, 실제 모바일 기기 검증, 배포·커밋은 이번 범위에 포함하지 않았다.


## 2026-09-06: 전면 홈·소개 랜딩과 대회 통합

### 변경
- Lusion·Unseen 실제 화면을 참고한 회백색 전면 히어로, 큰 LILAC 타이포, 세 개의 레코드·재킷 조형. 이번 시각 레퍼런스에서 Spotify·Apple Music은 제외했다.
- 독립 특설 허브·라우트·내비·반복 카드를 제거했다. 7개 회차의 선별 기록 48개와 출처를 awards/로 보존하고 홈 안에서 선택·펼침하도록 통합했다.
- 공식 이미지와 개별 구성은 docs/design-references.md 및 awards/ 출처 manifest를 따른다. NHK 이미지는 전재 제한 때문에 복제하지 않고 새 타이포·공식 링크를 사용한다. 다른 공식 에셋도 로컬 시안용이며 공개 전 사용 근거 확인이 필요하다.

### 이번 빌드의 실제 브라우저 검사
- 홈·소개·대회 7개 상태 × 320/390/768/1024/1440px = 45개 상태·폭 조합. URL 45개가 아니다. h1 하나, 문서·본문·대회 영역 가로 넘침 0, 깨진 가시 완료 이미지 0, 플레이어·하단 메뉴 겹침 0. 대회 35조합은 기록을 펼친 상태 및 선택된 패널 1개를 확인했다.
- 홈·소개 첫 화면 10조합에서 큰 제목의 가로 잘림 0, 헤더 가림 없음, 주요 조작부가 플레이어 또는 뷰포트 하단보다 위에 위치함을 확인했다. 소개의 320px 메뉴 넘침과 320~1024px 제목 잘림을 수정 후 재측정했다.
- 실제 WebGL canvas ready, 움직이는 두 화면의 차이, 모션 정지 후 두 화면의 동일함을 확인했다. 소개에서 끈 설정이 홈에 유지되고 이전 소개 canvas가 0개로 정리되는 것도 확인했다.
- 실제 WebGL context loss 후 fallback, 정적 이미지 3개, 키보드 링크 3개, 비활성 '정적 아트워크' 버튼을 확인했다. 이 상태에서 恋、はじめました。 · =LOVE 프리뷰가 실행되고 9초 이상 시간이 진행했으며 확인 후 정지했다.
- 대회 탭 Home/End/ArrowRight, tabindex=0 하나, Tab으로 패널·음악 링크 접근을 확인했다. MAMA 링크의 포커스 outline은 밝은 색 2px solid다. 소개 모바일 메뉴 열림 및 Escape 닫힘·버튼 포커스 복귀도 확인했다.
- 이전 #/specials는 실제 '페이지를 찾을 수 없습니다' 화면으로 처리된다. 독립 특설 링크는 45조합에서 0개다.
