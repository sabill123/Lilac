# Lilac 라일락

> 한국의 J-POP 팬과 일본의 K-POP 팬을 위한 공연·티켓·앨범·소식 허브.
> v6(2026-09-27)부터 모든 목록은 예매처·판매처·뉴스 원문에서 실시간으로 가져온다. 기획·BM·정보구조: [docs/v6-strategy.md](docs/v6-strategy.md)

## 실시간 데이터 (backend/lib/live)

| 모듈 | 원천 |
|---|---|
| `tickets-kr.mjs` | NOL 티켓(인터파크) 장르 API·오픈 공지, 멜론티켓 장르·티켓오픈소식 |
| `tickets-jp.mjs` | e+ K-POP 장르·검색(판매 일정 JSON), チケットぴあ K-POP 태그·검색 |
| `goods.mjs` | 알라딘, HMV&BOOKS online, Ktown4u JP |
| `news.mjs` | Google 뉴스 RSS(한/일), 스팸 제거·같은 사건 묶기 |
| `artist-info.mjs` | 출신국 판정(MusicBrainz→Apple 두 스토어→위키백과→로마자 대조), Deezer 사진(곡 목록으로 동일인 확인), 위키백과 소개·한국어 표기 |
| `cache.mjs` | TTL + stale-while-revalidate, 디스크 영속, 전부 실패 시 이전 값 유지, 내용이 바뀔 때만 `change` 이벤트 |
| `service.mjs` | 에디션별 조합, 투어 묶기, `/api/live/*` 라우트, 원천별 주기 동기화(`SYNC`)와 `/api/live/stream`(SSE) |
| `fanclub.mjs` | 공식 팬클럽 찾기·요금·선행 접수. 403(봇 차단)은 `http.mjs`의 HTTP/2 요청(curl)으로 한 번 더, 검색은 Yahoo → Brave → DDG |

**실시간 동기화**: 티켓 오픈 공지·뉴스 5분, 공연 10~20분, 팬클럽 선행 접수 30분마다 서버가 다시 받고, 바뀐 것만 SSE로 알린다. 화면은 지금 보는 페이지와 관련된 주제만 조작이 멈췄을 때 다시 그린다(스크롤 유지). 상태: `/api/live/status` → `realtime`.

CLI로 원천을 바로 확인할 수 있다: `npm run live:kr`, `npm run live:jp`, `npm run live:goods -- "YOASOBI" kr`.

## 검증

- `npm run test:v6` — 새 앱 계약(이모지·그라디언트 금지, 에디션·언어 연동, 하드코딩 금지, 번역 누락, 접근성, 홈 순서, 팬클럽 링크 추적)
- `npm run test:fanclub` — 팬클럽 선행 파서(공연 회차 배치 3종, 나라 판정, 팬클럽/일반 선행 구분, 모르는 값은 null). 네트워크 없이 합성 HTML로 돈다
- `npm run test:realtime` — 같은 내용 재수집은 알림 없음, 늘면 새 항목 수와 함께 알림, 실패·0건은 이전 값 유지
- `npm run test:community` — 갤러리(권한·익명 태그·추천 중복·개념글·검색·페이지·댓글·삭제·이미지 형식)와 좋아요·댓글 스냅샷. 메모리 저장소로 돈다
- `BASE=http://localhost:4600 npm run test:smoke` — 백엔드 전 엔드포인트 + 실시간 공연·티켓·뉴스·굿즈 계약
- 기존 `test:ui` 묶음은 v6 셸이 더 이상 마운트하지 않는 레거시 모듈(`src/pages.ts` 등)을 검사한다. 소개·약관 레이어는 그대로 쓴다.

### 주요 기능 깊이

- **플레이리스트**: 이름 변경 · 플리 내 검색 · 실제 곱 길이/총 재생시간 · 행 호버 액션 · 드래그 정렬(포인터 기반, 터치 지원) · 추천 항목 · 스티키 헤더
- **아티스트**: 인기곡 · 디스코그래피(실제 앨범) · 관련 일정/구즈 · 비슷한 아티스트 · 정보
- **일정**: 월별 리스트 ↔ 캘린더 뷰 토글, 유형 필터
- **스토어**: 카테고리 네비 · 정렬 · 상품 상세 탭(정보/배송·교환/판매자) · 관련 상품
- **i18n**: 지구본 메뉴로 한국어/日本語/English/中文 전환
- **플레이어**: 셔플 · 반복(1곡/전체) · 이전/다음 · 좋아요 · 플리 추가 · 재생목록(큐) 패널 · 볼륨
- **회원 데이터 구조**: `db/users.json`(계정·플랜·크레딧·결제수단) + `db/user/`(likes · playlists · history · orders · oshi · session)

## 디자인 시스템과 접근성

- 홈·소개 랜딩은 따뜻한 회백색 전면 구성, 차트·일반 음악 화면은 다크 UI, 스토어 목록은 별도의 밝은 커머스 진열면을 사용합니다. 토큰은 `frontend/src/styles/tokens.css`가 소유합니다.
- `shell.css`: 내비게이션·플레이어·도크·온보딩·모달·푸터
- `components.css`: 카드·버튼·폼·칩·상태 표현
- `discovery/`: 듣기 중심 홈·차트, 트렌드 분류·검증된 데뷔 정보·검색·재생 및 반응형 스타일. [구현·표시 기준](frontend/src/discovery/README.md)
- `awards/`: 홈 안에서 선택하는 7개 대회의 고유 비주얼·수상 기록·출처. 독립 특설 허브·상세 라우트는 제거했습니다. [출처·이미지 사용 범위](frontend/src/awards/README.md)
- `three/`: 지연 로드되는 세 개의 레코드·재킷 조형과 차트 아트워크. 모션 정지, reduced-motion, 화면 밖 정지와 정적 대체 화면
- `catalog.css`: 상품 상세·릴리스·아티스트·일정·보관함·검색·워크·계정·안내 화면
- `store/`: 스토어 목록의 모델·검색·필터·정렬·페이지네이션·카드·반응형 스타일. 브라우즈/플레이 셸에서 같은 목록을 사용합니다.
- `site/site.css`: 소개·요금·FAQ·문의·법무 페이지. 공통 토큰을 공유하고 별도 셸을 사용합니다.
- 레이어 순서: legacy → site → tokens → base → components → pages → motion. 소개의 전면 구성은 `site/landing-immersive.css`가 pages 레이어에서 소유합니다. 이전 `style.css`에 추가하지 않습니다.
- 홈·소개 랜딩은 큰 타이포와 실제 WebGL 레코드를 결합합니다. 모션 정지·정적 대체 화면을 제공하며 스크롤을 가로채지 않습니다. [2026-09-06 실제 디자인 레퍼런스](docs/design-references.md)
- 모바일: 검색, 5탭 하단 내비게이션과 미니 플레이어. 긴 표·선택 탭은 내부에서만 가로 스크롤합니다.
- 키보드: 재생 위치·볼륨 슬라이더는 화살표/Home/End와 ARIA 상태를 지원합니다. 비로그인 미리듣기는 기록 저장 없이 재생합니다.
- `/landing.html`은 중복 콘텐츠 대신 `/#/about`으로 이동합니다.

### 검증

`npm run build`는 타입 검사와 프로덕션 빌드를 수행합니다. `npm run test:ui`는 디자인·서비스 계약, 라우트 수명·플레이어·스토어·음악 발견·홈 대회·3D 생명주기 회귀 테스트를 실행하며 실제 구매를 만들지 않습니다.

`OUT=/absolute/tmp/audit npm run test:visual`은 독립 Chrome 프로필에서 1440×900 / 390×844 화면을 검사합니다. Node 22+와 설치된 Chrome이 필요합니다. macOS가 독립 Chrome 실행을 막으면 보고서에 blocked를 남기며 통과로 취급하지 않습니다.

## 데모에 들어있는 것

- **음악 발견**: 인기·상승·주목·신인 분류와 미리듣기를 먼저, 앨범·스토어 정보는 이후에 배치
- **MY 오시** — 최애 등록 (로컬 폴더 DB `db/user/oshi.json`에 저장)
- **라일락 차트**: Apple Music 카탈로그 실데이터(아트워크) + **30초 프리뷰 인앱 재생**
- **디스커버리** — 상단 검색 → Apple Music JP 스토어 실시간 검색
- **본진** — 내한·발매·응모 D-day 캘린더
- **굿즈 & 한정반** — YG셀렉트식 커머스 그리드 (데모)
- **플레이어 바** — 스포티파이식 하단 고정 + EQ 비주얼라이저 + 가사 패널(3단 표시 데모)
- **YouTube 공식 임베드** — 각 곡 MV 모달 재생
- **MusicKit 스캐폴드** — 개발자 토큰만 넣으면 구독자 풀트랙 재생으로 전환 (`frontend/src/musickit.ts`)

```bash

npm run dev
# 또는 각각
npm run dev:be
npm run dev:fe
```

접속: http://localhost:5180

### macOS 앱

```bash
# 네이티브 메뉴바 앱 빌드
npm run build:mac

# 빌드 후 실행
npm run run:mac
```

`macos/.build/Lilac.app`이 생성됩니다. 웹을 감싼 창이 아니라 SwiftUI 전용 사이드바·작업 보드·YouTube 플레이어를 사용하며, 메뉴바에서는 재생·작업 세션·자동 실행·업무 앱 볼륨 완화를 제어합니다. 자세한 내용은 `macos/README.md`를 참고하세요.

### Letsur GPT-5.4 연결

워크 모드는 키 없이 로컬 추천으로 동작합니다. GPT-5.4 큐레이터를 켜려면 브라우저가 아니라 백엔드 프로세스에만 환경변수를 설정합니다.

```bash
export LETSUR_API_KEY='새로 발급한 키'
export LETSUR_MODEL_CODE='gpt-5.4'
npm run dev
```

키를 소스·`.env` 커밋·프론트엔드 코드에 넣지 마세요.
