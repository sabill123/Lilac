# Lilac 라일락 💜

> **"당신의 오시에게 닿는, 국경 없는 가장 가까운 길."**
> 한국의 J-POP 팬과 일본의 K-POP 팬을 위한 크로스보더 팬덤 플랫폼 — 데모 웹.

## 두 가지 모드

| 모드 | 레이아웃 | 적용 화면 |
|---|---|---|
| **브라우즈(기본)** | 상단 GNB + 풀블리드 | 홈 · 차트 · 스토어 · 일정 · 아티스트 · 계정 |
| **플레이** | 스포티파이 셸(좌측 라이브러리 사이드바 + 라운드 패널 + 우측 대기열) | 보관함 · 플레이리스트 (자동), 플레이어 버튼으로 수동 전환 |

계정 화면(로그인·가입·마이페이지)는 항상 브라우즈 모드로 고정됩니다.

## 페이지 구성

| 라우트 | 페이지 |
|---|---|
| `#/` | 홈 — 빌보드 · 아티스트 · 차트 TOP5 · 다가오는 일정 · 스토어 신상 |
| `#/chart/{combined\|apple\|youtube}` | 실시간 차트 — 종합 / Apple Music(실시간 공식 피드) / YouTube(공식 MV 조회수) |
| `#/library/{all\|playlists\|artists\|likes\|history}` | 보관함 — 필터 칩 · 검색 · 정렬 · 그리드/리스트 토글 · 우클릭 메뉴 |
| `#/search?q=` | 검색 — 상위 결과 카드 + 탭(전체/곡/아티스트/앨범) |
| `#/store` · `#/store/:id` | 스토어 목록 · 상품 상세(공식 운영사 표기 + 공식 스토어/타워레코드 외부 링크 + 크레딧 예약 주문) |
| `#/schedule` | 일정 — 내한 · 발매 · 응모 D-day |
| `#/artist/:id` | 아티스트 — 팔로우 · 인기곡 · 관련 일정/국즈 · 공식 사이트 링크 |
| `#/library/{likes\|playlists\|history\|follows}` | 보관함 — 좋아요 · 플레이리스트 · 최근 재생 · 팔로우 |
| `#/playlist/:id` | 플레이리스트 상세 (전체 재생/곱 삭제) |
| `#/login` · `#/signup` | 로그인 · 회원가입 (웰컴 크레딧 5,000) |
| `#/account` | 계정 — 프로필 · 플랜 · 크레딧 충전 · 결제수단 · 주문내역 · 로그아웃 |
| `#/search?q=` | Apple Music 카탈로그 검색 |

### 주요 기능 깊이

- **플레이리스트**: 이름 변경 · 플리 내 검색 · 실제 곱 길이/총 재생시간 · 행 호버 액션 · 드래그 정렬(포인터 기반, 터치 지원) · 추천 항목 · 스티키 헤더
- **아티스트**: 인기곡 · 디스코그래피(실제 앨범) · 관련 일정/구즈 · 비슷한 아티스트 · 정보
- **일정**: 월별 리스트 ↔ 캘린더 뷰 토글, 유형 필터
- **스토어**: 카테고리 네비 · 정렬 · 상품 상세 탭(정보/배송·교환/판매자) · 관련 상품
- **i18n**: 지구본 메뉴로 한국어/日本語/English/中文 전환
- **플레이어**: 셔플 · 반복(1곡/전체) · 이전/다음 · 좋아요 · 플리 추가 · 재생목록(큐) 패널 · 볼륨
- **회원 데이터 구조**: `db/users.json`(계정·플랜·크레딧·결제수단) + `db/user/`(likes · playlists · history · orders · oshi · session)

## 인터랙션 · 모션

- 아트워크 **대표색 자동 추출**(canvas) → 플리/아티스트/차트/히어로 헤더 그라디언트
- 커서 추적 **3D 틸트 + 글레어**, 넷플릭스식 호버 확장 카드
- 플레이어 **바이닐 디스크**(재생 중 회전), **전체화면 나우플레잉**(3D 부유 커버)
- 패럴랙스 히어로, 스켈레톤 로딩, 페이지 전환 스태거 모션, 리플
- 키보드 단축키: `Space` 재생/정지, `←→` 탐색, `Shift+←→` 이전/다음, `Q` 대기열, `L` 가사, `H` 좋아요, `/` 검색
- 우클릭 컨텍스트 메뉴(트랙/보관함 항목), 대기열 드래그 정렬
- 모바일: 하단 5탭 네비, 터치 타깃 36px 보장, 테이블 간소화 (390px 실측 검증)

## 데모에 들어있는 것

- **홈 히어로** — 넷플릭스식 풀블리드 + 키네틱 타이포 + 마퀴 티커
- **MY 오시** — 최애 등록 (로컬 폴더 DB `db/user/oshi.json`에 저장)
- **라일락 차트** — Apple Music 카탈로그 실데이터(아트워크) + **30초 프리뷰 인앱 재생**
- **디스커버리** — 상단 검색 → Apple Music JP 스토어 실시간 검색
- **본진** — 내한·발매·응모 D-day 캘린더
- **굿즈 & 한정반** — YG셀렉트식 커머스 그리드 (데모)
- **플레이어 바** — 스포티파이식 하단 고정 + EQ 비주얼라이저 + 가사 패널(3단 표시 데모)
- **YouTube 공식 임베드** — 각 곡 MV 모달 재생
- **MusicKit 스캐폴드** — 개발자 토큰만 넣으면 구독자 풀트랙 재생으로 전환 (`frontend/src/musickit.ts`)

## 실행

```bash
# 백엔드 (포트 4600) + 프론트 (포트 5180) 동시 실행
npm run dev
# 또는 각각
npm run dev:be
npm run dev:fe
```

접속: http://localhost:5180

## 구조

```
Lilac/
├─ frontend/   # Vite + TypeScript + 커스텀 CSS 디자인 시스템
├─ backend/    # Express — iTunes 카탈로그 프록시 + 로컬 폴더 DB API
└─ db/         # 로컬 폴더 DB (JSON): artists / tracks / events / products
   └─ user/    # 유저 기록 (오시 등록)
```

## 재생 아키텍처

| 경로 | 방식 | 조건 |
|---|---|---|
| ▶ 프리뷰 | Apple Music 카탈로그 30초 프리뷰 — 인앱 `<audio>` 재생 | 없음 (공개 API) |
| ▷ MV | YouTube 공식 임베드 (`youtube-nocookie.com`) | 없음 |
| 풀트랙 (준비됨) | MusicKit JS — Apple ID 1회 인증 후 인앱 풀트랙 | Apple 개발자 토큰 + 유저의 애플뮤직 구독 |

## 디자인 레퍼런스

스포티파이(하단 플레이어 바) · 넷플릭스(히어로/카드 행) · 애플뮤직(글래스 네비/라운드 카드) · 라프텔(태그 칩 탐색) · YG셀렉트(굿즈 그리드) 패턴을 라일락 아이덴티티(#C77DFF 라일락 퍼플, 다크 퍼스트)로 재해석.
