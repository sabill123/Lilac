# Lilac for macOS

SwiftUI와 AppKit으로 만든 독립형 업무 집중 플레이어입니다. 전체 웹 서비스를 감싼 셸이 아니라, macOS에 맞춘 사이드바·집중 타이머·메뉴바 컨트롤을 사용합니다. YouTube는 플레이어 영역에만 공식 IFrame API로 삽입됩니다.

## 빌드와 실행

웹/API 서버 없이 단독으로 실행할 수 있습니다.

```bash
npm run build:mac
open macos/.build/Lilac.app
```

음원과 썸네일을 불러오려면 인터넷 연결이 필요합니다.

## 네이티브 기능

- 한 가지 할 일과 25·45·60·90분 작업 프리셋
- YouTube 업무 믹스 재생·일시정지·이전·다음
- 실제 YouTube 플레이어에 직접 연결된 볼륨 슬라이더
- 전체 창을 닫아도 유지되는 메뉴바 플레이어
- 로그인 시 자동 실행 (`SMAppService`)
- Slack/Codex/Claude/VS Code 전환 시 짧은 스마트 볼륨 완화
- Zoom/Teams/Webex 활성 중 회의용 볼륨 완화
- 완료한 작업 세션의 로컬 기록

macOS는 다른 앱이 발행한 모든 알림을 읽는 공개 API를 제공하지 않습니다. 현재 버전은 알림 내용을 수집하지 않고 앱 활성화를 프라이버시 친화적인 신호로 사용합니다. 알림 단위 연동은 각 서비스 공식 API 또는 사용자가 명시적으로 허용한 접근성 권한으로 별도 설계해야 합니다.
